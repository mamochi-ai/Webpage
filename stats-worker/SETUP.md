# アクセスランキングの準備（Cloudflare の画面だけでできます）

iPad の Safari でも操作できます。所要時間は 10 分ほどです。費用は無料枠の範囲で収まります。

## 1. データベース（D1）を作る

1. https://dash.cloudflare.com にログイン（アカウントがなければ無料で作成）
2. 左のメニュー「ストレージとデータベース」→「D1 SQL データベース」→「データベースを作成」
3. 名前を `mamochi-stats` にして作成

表（テーブル）は Worker が最初のアクセスで自動で作るので、ここでの作業はこれだけです。

## 2. Worker を作る

1. 左のメニュー「Workers & Pages」→「作成」→「Worker を作成」（「Hello World から始める」）
2. 名前を `mamochi-stats` にして「デプロイ」
3. 「コードを編集」を開き、中身をすべて消して、このフォルダの `worker.js` の中身を貼り付ける
4. 右上の「デプロイ」

## 3. Worker とデータベースをつなぐ

1. 作った Worker の画面 →「設定」→「バインディング」→「バインディングを追加」
2. 「D1 データベース」を選ぶ
3. 変数名を **`DB`**（大文字）、データベースを `mamochi-stats` にして保存

## 4. 動作確認

Worker の URL（`https://mamochi-stats.<あなたのサブドメイン>.workers.dev`）をブラウザで開いて、
`{"ok":true,"service":"mamochi-stats"}` と出れば完成です。

この URL を `assets/js/data.js` の `statsApi` に入れると、サイトにランキングが表示されます。

```js
statsApi: "https://mamochi-stats.xxxx.workers.dev",
```

## 数えているもの

| 種類 | いつ数えるか |
| --- | --- |
| 詳細 (`view`) | このサイトで作品の詳細を開いたとき |
| 開いた (`open`) | 詳細の「サイトを見る」「遊んでみる」を押したとき |

- 同じ人・同じ作品・同じ種類は 1 日 1 回まで（日本時間）
- 保存するのは「日付・作品・種類・回数」だけ。IP アドレスや端末の情報は保存しません
  （1 日 1 回の判定に使う値は、元に戻せない形に変換して 2 日で消します）
- 受け付けるのは `https://mamochi-ai.github.io` からのアクセスだけです

## おまけゲーム（Mochi Hop）のスコアランキング

`worker.js` にスコア用の機能も入っています。Worker を作ったあとで `worker.js` が更新された場合は、
「Edit code」で中身を新しい `worker.js` に貼り替えて「Deploy」してください（データベースやバインディングはそのままで大丈夫です）。

- ゲーム開始時に整理券を受け取り、ゲームオーバー後に 1 回だけスコアを登録できます
- 開始からの経過時間に対してありえない点数（1 秒あたり約 60 点を超えるもの）は受け付けません
- ニックネームは 12 文字まで。不適切な名前を消したいときは、D1 の画面（mamochi-stats →「Console」）で
  `DELETE FROM scores WHERE name = '消したい名前';` を実行してください
